# Freshban-V.2
FreshBan est un panel de bannissement et de modération pour FiveM, entièrement gérable en jeu. Sanctions, kick, grades et permissions, webhooks Discord et rôles Discord liés aux grades : tout se configure depuis l'interface. Installation automatique de la base de données, aucun ACE ni SQL à importer, et sécurité côté serveur contre les injections.
